# Funmodio

Agent-first motion video studio. This repository holds the releases only.

## Download

| Platform              | Download                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| macOS (Apple silicon) | [Funmodio-macos-arm64.dmg](https://github.com/<owner>/funmodio-release/releases/latest/download/Funmodio-macos-arm64.dmg)             |
| macOS (Intel)         | [Funmodio-macos-x64.dmg](https://github.com/<owner>/funmodio-release/releases/latest/download/Funmodio-macos-x64.dmg)                 |
| Windows               | [Funmodio-windows-x64-setup.exe](https://github.com/<owner>/funmodio-release/releases/latest/download/Funmodio-windows-x64-setup.exe) |

| Linux (Debian/Ubuntu) | [Funmodio-linux-amd64.deb](https://github.com/<owner>/funmodio-release/releases/latest/download/Funmodio-linux-amd64.deb)             |

All versions and notes: [Releases](https://github.com/<owner>/funmodio-release/releases). Checksums are in
`SHA256SUMS` on each release.

## Updates

Funmodio checks for updates in the background and downloads them fully before offering "Restart to update". Updates
are signed; the app refuses anything that is not.
